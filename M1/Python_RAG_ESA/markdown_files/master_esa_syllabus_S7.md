## Programmation SAS

- **Enseignant** : Sébastien RINGUEDÉ
- **Année** : M1 | **Semestre** : 7
- **Nature** : CM | **Volume horaire** : 30h | **ECTS** : 5
- **Prérequis** : Aucun

### Résumé

Ce cours présente l'ensemble des fondamentaux de Base SAS, module sur lequel est fondé le système SAS, et dont la connaissance est nécessaire à tous ses utilisateurs quels que soient leurs objectifs. Les outils de création, de lecture, de modification et de combinaison des tables SAS sont abordés. On traite également de la création et de la modification des variables de type caractère ou numérique et des principaux formats applicables. Enfin, ce cours donne un aperçu de quelques procédures de primo-exploitation des données (impression, tableaux croisés, statistiques de base) ainsi que de la construction de graphiques.

### Objectifs

Vise à l'obtention d'une bonne maîtrise des concepts et outils constitutifs de Base SAS : l'étudiant doit à son issue avoir une compréhension quasi-exhaustive du programme de la certification Base Programming for SAS 9, qu'ils seront invités à passer au cours du second semestre de M1.

### Plan du cours

1. Faire connaissance avec son environnement SAS
2. Aller plus loin dans la création de tables SAS
3. Modifier les tables SAS
4. Combiner les tables SAS
5. La gestion des tables SAS
6. Les procédures de base
7. Produire des graphiques

### Bibliographie

- Sébastien Ringuedé, *SAS – introduction au décisionnel : du data management au reporting*, 4ème édition, Eyrolles, 2019

## Programmation R

- **Enseignant** : Abdoul-Aziz N'DOYE
- **Année** : M1 | **Semestre** : 7
- **Nature** : CM | **Volume horaire** : 24h | **ECTS** : 2
- **Prérequis** : Notions de base en statistique et économétrie

### Résumé

R est un langage de programmation d'une syntaxe voisine à celle du langage S, capable de manipuler des objets complexes sous forme d'objet. Il dispose d'une très riche bibliothèque ("package") de quasiment toutes les procédures et méthodes statistiques. Cet enseignement est un apprentissage de R en tant que logiciel statistique dans le traitement exploratoire de données statistiques et en tant que langage de programmation interprété.

### Objectifs

- Découvrir le logiciel et apprendre à organiser son travail sous R
- Comprendre les principaux objets de données et apprendre à les manipuler
- Savoir appliquer les fonctions disponibles dans les packages
- Décrire ses données et réaliser ses premières visualisations
- Programmer sous R : écrire un algorithme, créer de nouvelles fonctions de traitement de données
- Manipuler les fonctions des packages connectés du Tidyverse

### Plan du cours

1. Utilisation de R comme un logiciel de traitement statistique des données
   - 1.1 Présentation générale du logiciel et de l'environnement R (description, commandes de base, éditeurs de texte, aide en ligne, installation et utilisation des packages)
   - 1.2 Manipulation d'objets sous R (vecteurs, matrices, listes et data frame ; données externes ; fonctions de packages ; représentation graphique)
2. Programmation modulaire sous R
   - 2.1 Les structures de contrôle : alternatives et boucles
   - 2.2 Création de nouvelles fonctions de traitement de données
   - 2.3 Écriture d'algorithme en langage R
3. Manipulation des fonctions des différents packages connectés de Tidyverse
   - 3.1 Cadres de données type tibble
   - 3.2 Transformation des données avec dplyr
   - 3.3 Importation et exportation avec readr
   - 3.4 Rangement des données avec tidyr
   - 3.5 Visualisation avec ggplot2
   - 3.6 Création de fonctions sous Tidyverse

### Bibliographie

- Baumer B. & Horton J., CRC Press (2021), *Modern Data Science with R* (2nd ed.)
- Chambers J., CRC Press (2016), *Extending R*
- Wickham H., CRC Press (2019), *Advanced R* (2nd edition)
- Wickham H. & Grolemund G., O'Reilly (2017), *R for Data Science*
- Documentation en ligne : cran.r-project.org

## Programmation Python

- **Enseignant** : Mathieu LIEDLOFF
- **Année** : M1 | **Semestre** : 7
- **Nature** : CM | **Volume horaire** : 24h | **ECTS** : 2
- **Prérequis** : Connaissances de base en Python

### Résumé

Ce cours propose une initiation progressive à la programmation en Python, spécifiquement adaptée aux besoins de l'économie. Après une révision des bases (variables, boucles, conditionnelles, fonctions), les étudiants apprendront à manipuler des données textuelles et numériques, à gérer les exceptions et à utiliser les structures avancées du langage (listes, dictionnaires, tuples). Un focus sera mis sur la conception de classes et la programmation orientée objet. Le cours introduira également des bibliothèques incontournables en analyse économique et statistique : NumPy pour les calculs sur tableaux, Matplotlib pour la visualisation, et éventuellement une première approche de Scikit-learn pour la modélisation prédictive.

### Objectifs

- Maîtriser les bases de la programmation en Python (structures de contrôle, fonctions, classes)
- Manipuler efficacement des chaînes de caractères
- Utiliser les structures de données clés de Python (listes, dictionnaires, tuples)
- Gérer les erreurs par l'usage des exceptions
- Développer des programmes simples avec des classes et la POO
- Lire, écrire et traiter différents formats de fichiers (texte brut, CSV, JSON)
- Avoir des notions de base sur NumPy (manipulation de tableaux, calculs numériques) et Matplotlib (création de graphiques)

### Plan du cours

1. Introduction et rappels de Python
2. Chaînes de caractères
3. Structures de données avancées
4. Programmation orientée objet
5. Tests
6. Exceptions et gestion d'erreurs
7. Manipulation de fichiers
8. Introduction à NumPy
9. Visualisation avec Matplotlib
10. Vers l'apprentissage automatique

## Statistique Mathématique

- **Enseignant** : Christophe HURLIN
- **Année** : M1 | **Semestre** : 7
- **Nature** : CM + TD | **Volume horaire** : 30h CM + 15h TD | **ECTS** : 5
- **Prérequis** : Cours de probabilité (probabilité, variables aléatoires, etc.) ; Cours de statistique descriptive

### Résumé

Le cours de statistique mathématique se structure autour de 6 grands chapitres : théorie de l'estimation, méthode du maximum de vraisemblance, théorie de l'inférence statistique, modèle de régression linéaire, hétéroscédasticité, endogénéité et méthodes de variables instrumentales. Ce cours constitue un prérequis indispensable à l'ensemble des autres cours du master (première année et deuxième année). Les slides du cours sont rédigés en anglais afin de faciliter l'acquisition du vocabulaire technique, mais le cours est dispensé en français. Les concepts théoriques seront illustrés par des applications réalisées sous Python et exécutées sous Google Colab.

### Objectifs

- Maîtriser les concepts d'échantillon, d'estimateur, d'estimation
- Maîtriser les différentes notions de convergence d'une suite de variables aléatoires
- Maîtriser les principaux théorèmes de la statistique mathématique (théorème central limite, loi faible des grands nombres, méthode delta, etc.)
- Savoir dériver les propriétés à distance finie et les propriétés asymptotiques d'un estimateur
- Maîtriser les principales notions associées aux tests statistiques (région critique, statistique de test, p-value, etc.)
- Maîtriser les tests de Student et de Fisher
- Maîtriser les tests LRT, Wald et LM
- Maîtriser la théorie du maximum de vraisemblance (gradient, score, hessienne, matrice d'information de Fisher)
- Savoir dériver les propriétés asymptotiques de l'estimateur du maximum de vraisemblance
- Comprendre le principe des principales méthodes d'optimisation numérique et savoir les implémenter sous Python
- Comprendre les implications de l'hétéroscédasticité et de l'endogénéité
- Maîtriser les méthodes d'estimation GLS, FGLS, WLS et la correction de White
- Maîtriser les méthodes de type variables instrumentales (IV) et 2SLS

### Plan du cours

1. **Chapter 1 — Estimation theory** : Introduction ; What is an estimator? ; Finite sample properties ; Large sample (asymptotic) properties (almost sure convergence, convergence in probability, convergence in mean square, convergence in distribution, asymptotic distributions)
2. **Chapter 2 — Maximum Likelihood Estimation (MLE)** : Introduction ; The principle of MLE ; The likelihood function ; Maximum likelihood estimator ; Score, Hessian and Fisher information ; Properties of MLE
3. **Chapter 3 — The multiple linear regression model: the OLS estimator** : Introduction ; The multiple linear regression model ; The OLS estimator ; Statistical properties (finite sample + asymptotic)
4. **Chapter 4 — Inference and statistical hypothesis testing** : Introduction ; Statistical hypothesis testing ; Tests in the multiple linear regression model (Student test, Fisher test) ; MLE and Inference (LR test, Wald test, LM test)
5. **Chapter 5 — The Generalized Least Squares (GLS) estimator** : Introduction ; The generalized linear regression model ; Inefficiency of OLS ; GLS ; Heteroscedasticity ; Testing for heteroscedasticity
6. **Chapter 6 — Endogeneity, error-in-variables and the IV estimator** : Introduction ; Endogeneity ; IV estimator ; Two-Stage Least Squares (2SLS)

### Bibliographie

- Amemiya T. (1985), *Advanced Econometrics*, Harvard University Press
- Greene W. (2007), *Econometric Analysis*, sixth edition, Pearson – Prentice Hill
- Hurlin C. and Mignon V. (2022), *Statistique et Probabilités*, Dunod, 2nd édition
- Ruud P. (2000), *An introduction to Classical Econometric Theory*, Oxford University Press

## Séries temporelles univariées

- **Enseignant** : Gilles DE TRUCHIS
- **Année** : M1 | **Semestre** : 7
- **Nature** : CM + TD | **Volume horaire** : 30h CM + 15h TD | **ECTS** : 6
- **Prérequis** : Cours de statistiques (estimation par le maximum de vraisemblance, propriétés des estimateurs, théorie des tests) ; Cours d'économétrie linéaire (estimation OLS, GLS, FGLS)

### Résumé

Ce cours est une présentation d'outils utilisés pour la modélisation de séries univariées. Il s'agit notamment d'apprendre à modéliser et à construire des prévisions sur l'espérance conditionnelle d'une variable économique stationnaire ou intégrée. On aborde notamment l'estimation et l'identification des processus ARMA, les tests de diagnostic, les processus à racine unitaire et à trend déterministe. Les chapitres sont ponctués d'exemples, d'exercices et de cas pratiques.

### Objectifs

- Maîtriser les trois étapes de la méthodologie de Box-Jenkins : identification, estimation, validation des filtres ARMA(p,q)
- Maîtriser le processus de construction de prévisions d'une série temporelle pour différents horizons avec calcul des intervalles de confiance associés
- Être capable de prendre en compte une saisonnalité éventuelle en considérant la classe des processus SARIMA(p,d,q)×(P,D,Q)s
- Comprendre les propriétés des processus non stationnaires à trend déterministe ou stochastique ; savoir réaliser les tests de racine unitaire les plus populaires et interpréter leurs résultats

### Plan du cours

1. **Chapitre 1 — Les processus ARMA** : Introduction ; Propriétés des séries temporelles ; AR et MA ; Stationnarité et inversibilité ; Les processus ARMA ; Les prévisions des ARMA
2. **Chapitre 2 — Estimation et sélection de modèle** : Le maximum de vraisemblance ; Newey-West ; Le principe du QMLE ; Sélection de modèles ; Tests de diagnostic
3. **Chapitre 3 — Non-stationnarité et tendances** : Tendances stochastiques et déterministes ; Processus fractionnairement intégrés ; La saisonnalité et les SARMA ; Estimateurs usuels et non-stationnarité ; Introduction à la théorie limite non-standard ; Tests de racine unitaire ; Régression factice

### Bibliographie

Manuels techniques :
- Hamilton, *Time Series Analysis*, Princeton University Press, 1994
- Brockwell and Davis, *Introduction to Time Series and Forecasting*, Springer, 2016

Manuels d'applications :
- Walter Enders, *Applied Econometric Time Series*, 3rd ed., John Wiley & Sons, 2009
- Ruey S. Tsay, *Analysis of Financial Time Series*, John Wiley & Sons, 2005
- John C. Brocklebank & David A. Dickey, *SAS for Forecasting Time Series*, 2nd ed., SAS Institute Inc.

## Analyse des données qualitatives : ACM

- **Enseignant** : Nils BERGLUND
- **Année** : M1 | **Semestre** : 7
- **Nature** : CM | **Volume horaire** : 24h | **ECTS** : 2
- **Prérequis** : Notions de base de statistiques (intervalle de confiance, test du chi-deux) ; Notions de base de calcul matriciel (changement de base, valeurs propres) ; Des rappels sur l'ACP seront faits au début du cours

### Résumé

L'analyse des données qualitatives concerne les jeux de données comprenant deux variables qualitatives ou plus. Le but est d'obtenir une représentation graphique optimale des différentes modalités sur un espace de dimension réduite. Cette représentation permet de déterminer les facteurs principaux distinguant les modalités, de représenter les corrélations entre modalités, et d'identifier des groupes de modalités proches, première étape vers une classification des données.

### Objectifs

- Comprendre les principes de base mathématiques justifiant les méthodes expliquées dans le cours
- Être capable d'interpréter les résultats d'une AFC ou d'une ACM (discussion des inerties, interprétation des axes, mise en évidence de modalités particulières)

### Plan du cours

1. Analyse en composantes principales
2. Analyse factorielle des correspondances
3. Analyse des correspondances multiples

Page du cours : http://www.univ-orleans.fr/mapmo/membres/berglund/m1_esa.html

### Bibliographie

- L. Lebart, A. Morineau, M. Piron, *Statistique exploratoire multidimensionnelle*, Dunod, 2006
- X. Bry, *Analyses factorielles simples*, Economica, 1995

## Apprentissage statistique et classification

- **Enseignant** : Amine LAHIANI
- **Année** : M1 | **Semestre** : 7
- **Nature** : CM | **Volume horaire** : 24h | **ECTS** : 2
- **Prérequis** : Cours d'analyse de données ; Cours d'algèbre linéaire ; Cours de géométrie dans l'espace

### Résumé

Ce cours présente les bases des techniques d'apprentissage statistique et de classification les plus répandues. Il détaille tout particulièrement l'analyse discriminante, avec une introduction de concepts bayésiens de classification (via la méthode knn), la validation croisée pour évaluer la robustesse et/ou la précision d'un modèle. Il traite également des arbres de décision (CART — Classification and Regression Trees). Il s'agit de donner aux étudiants des outils utiles pour analyser des données complexes et éventuellement massives. Ces techniques sont mises en œuvre au moyen du logiciel R.

### Objectifs

- Maîtriser les techniques d'apprentissage et de classification
- Modélisation pour la prévision
- Recherche de modèles optimaux et parcimonieux
- Fouille de bases de données volumineuses
- Utilisation de logiciels statistiques de fouille des données
- Donner une interprétation simple d'une base de données complexe

### Plan du cours

1. Introduction
2. k-nearest neighbors
3. Arbres de décision (introduction, arbre de classification, arbres vs modèles linéaires, avantages et inconvénients, applications)
4. Méthodes de classification non linéaires (régression polynomiale, fonctions échelons, régression locale, modèles généralisés additifs, applications)

### Bibliographie

- L. Breiman, J. Friedman, R. Olshen et C. Stone, *Classification and regression trees*, Wadsworth & Brooks, 1984
- T. M. Cover et P. E. Hart, *Nearest neighbor pattern classification*, IEEE Trans. Inform. Theory 13 (1967), 21–27
- J. H. Friedman, H. Hastie et R. Tibshirani, *Additive logistic regression: a statistical view of boosting*, The Annals of Statistics 28 (2000), 337–407
- B. Ghattas, *Agrégation d'arbres de classification*, Revue de Statistique Appliquée 48 (2000), no. 2, 85–98
- L. Rokach et O. Maimon, *Data mining with decision trees: theory and applications*

## Finance quantitative

- **Enseignant** : Alexis DIRER
- **Année** : M1 | **Semestre** : 7
- **Nature** : CM | **Volume horaire** : 24h | **ECTS** : 2
- **Prérequis** : Cours de statistiques (L3) ; Cours d'Introduction à la finance (L3) ; Initiation aux logiciels R et Python

### Résumé

Après une présentation des principaux concepts de la finance (l'aversion au risque, la valeur fondamentale, la condition de non-arbitrage, la diversification financière), le cours introduit la théorie moderne des choix de portefeuille (Markowitz), les théories de gestion dynamique de portefeuille et enfin la théorie de la valorisation des prix des actifs à l'équilibre (MEDAF). L'accent est porté sur l'analyse quantitative des prix au moyen des logiciels R et Python.

### Objectifs

- Présenter des outils quantitatifs et modèles mathématiques clés utilisés en finance de marché
- Introduire dans un cadre formel des techniques quantitatives pour la gestion des risques financiers
- Illustrer les modèles théoriques par des applications empiriques sous R et Python

### Plan du cours

1. **Introduction**
2. **Partie 1 — Risque et prix** : Définition du risque ; Les préférences face aux risques ; Le prix d'une action et la condition de non-arbitrage ; *Application Python : Importer des prix financiers et calculer des rendements composés*
3. **Partie 2 — Rendements et risque** : Les mesures du rendement (*Application Python : Peut-on prédire les rendements journaliers ?*) ; Statistiques de rendement et risque (*Application Python : La diversification de portefeuille*) ; Mesurer le risque des titres à revenu fixe ; Modéliser les rendements financiers ; Modéliser les prix des actifs (*Application Python : Modéliser le prix BTC/USD*) ; La prime de risque des actions (*Application Python : Calculer la prime de risque historique*)
4. **Partie 3 — Choix de portefeuille : Markowitz** : Les préférences espérance-variance ; Le modèle à deux titres ; Plus de deux titres (*Applications Python : espace des portefeuilles à 2, 3 et n titres ; Retour sur la diversification*) ; Ajout d'un titre sans risque ; Portefeuille optimal
5. **Partie 4 — Choix dynamiques de portefeuille** : Portefeuilles de parité des risques ; Ciblage de la volatilité ; Rebalancement de portefeuille (*Application Python*) ; Pondération des actifs (*Application Python : Stratégie de Kelly*) ; Choix de portefeuille et horizon d'investissement (*Application Python : Diversification temporelle*)
6. **Partie 5 — Valorisation des titres (MEDAF)** : Introduction ; La droite de capital ; Interprétations graphiques ; La condition de non-arbitrage (*Application Python : construction d'un modèle CAPM*) ; Validation empirique ; Évaluer la performance des fonds ; Principes d'investissement

Site du cours : https://tinyurl.com/ORLESAFIQ

### Bibliographie

- *Gestion de Portefeuille et Marchés Financiers* (2e éd., 2017), Ed. Pearson
- *Capital Ideas: The Improbable Origins of Modern Wall Street* (English Edition)
