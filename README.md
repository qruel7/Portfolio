# Portfolio — Quentin Ruel

Étudiant en Master 2 ESA (Économétrie et Statistique Appliquées) à l'Université d'Orléans. Ce dépôt rassemble mes projets académiques de la Licence au Master, en économétrie, statistique appliquée et data science.

## Compétences techniques

- **Langages** : R, Python, SAS, LaTeX
- **Économétrie / statistique** : modèles Logit/Probit, séries temporelles et décomposition, tests d'hétéroscédasticité, sélection de variables (stepwise), analyse en composantes principales
- **Data science** : préparation et nettoyage de données, machine learning (scikit-learn), visualisation (`ggplot2`, `matplotlib`, `plotly`), traitement du langage naturel - NLP (embeddings sémantiques, recherche vectorielle, ChromaDB, sentence-transformers)
- **IA générative** : architecture RAG (Retrieval-Augmented Generation), ingénierie du prompt, intégration d'API LLM (Groq), développement d'interface conversationnelle (Chainlit)
